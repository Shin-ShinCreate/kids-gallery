# キッズギャラリー（バージョン 1.1.0）

捨てられない子どもの作品・ことば・プレゼントを、写真に撮ってしまっておくWebアプリ（PWA）。
データはすべて端末のブラウザ内（IndexedDB）に保存され、サーバーには送られません。

## 実装した機能（アイデア番号）

| No. | 機能 | 場所 |
|---|---|---|
| 1 | 「ありがとう、さようなら」儀式モード（声の録音＋演出、手放した日を記録） | 作品の詳細 / 保存時 / 連続撮影のまとめ |
| 2 | 現物の保管状況（手元・実家・手放した）＋保管箱＋QRラベル印刷 | 下のタブ「保管」 |
| 5 | 連続撮影（手がどいて静止したら自動撮影）＋まとめて整理 | ホーム「連続撮影」 |
| 6 | 自動補正（四隅検出・ゆがみ補正・紙を白く）＋手動で四隅調整 | 写真を追加したとき |
| 8 | 年齢・学年の自動付与（4/2〜翌4/1区切り、年少〜中学） | すべての作品 |
| 9 | 名言帳・言い間違い辞典（音声入力・声の録音） | 下のタブ「ことば」 |
| 10 | プレゼントの物語カード＋「N年前の今日」表示 | ホーム「プレゼント」・ホームの思い出欄 |
| 20 | まるごと書き出し（フォルダ構成のZIP）・復元・作品集（印刷/PDF） | 右上 ⚙️ |

## MUSEUM の強みを取り入れた機能（追加分）

| 機能 | 内容 | 場所 |
|---|---|---|
| 補正の手動調整 | 回転（左右90°）・明るさ・あざやかさを、自動補正のあとで微調整 | 写真を追加したときの画面 |
| 背景の切り抜き | 紙や机の背景を透明にして、絵の部分だけを取り出す（絵の中の白は残る）。強さはスライダーで調整 | 作品の詳細 →「グッズのイメージを作る」 |
| グッズのイメージ | Tシャツ・スマホケース・トートバッグ・アクリルキーホルダーにのせたイメージ画像を保存。透明PNGも保存できる（注文機能はなし） | 同上 |
| 作品集（ART BOOK）の自動作成 | 表紙・年度ごとの章扉・作品ページ・ことば集・奥付を自動レイアウト。A4/A5、スタンダード/プレミアム（額縁）、1ページ1/2/4点、表紙と掲載作品の選択、ページ数は4の倍数に調整。PDF保存・印刷 | ホーム「作品集をつくる」 |
| 作品集のお知らせ | 作品が12点たまるごとに、ホームでお知らせ | ホーム |

### サーバー（cloud-api）を更新するとき
`schema.sql` に表（`devices` / `device_invites`）が増えています。次の順で反映してください（古いメンバーはそのまま使え、はじめて使ったときに自動で端末へ引っ越します）。

```bash
cd cloud-api
npx wrangler d1 execute kids-gallery --remote --file schema.sql
npx wrangler deploy
```

## パソコンで試す

```bash
python -m http.server 8765
```

ブラウザで http://localhost:8765 を開く（このフォルダで実行）。

## スマホで試す（カメラ・マイクを使うには https が必要）

GitHub Pages などで公開すると、スマホで開いて「ホーム画面に追加」でアプリのように使えます。

## ファイル構成

- `index.html` … 画面の骨組み
- `app.js` … 画面と機能
- `imaging.js` … 画像処理（四隅検出・射影変換・色補正・動き検出）
- `db.js` … データ保存（IndexedDB）
- `style.css` … デザイン
- `cloud.js` / `cloud-api/` … 家族共有（クラウド同期）と、そのサーバー
- `sw.js` / `manifest.json` / `icon*.svg` / `icon-*.png` … PWA（オフライン対応・ホーム画面追加）
