# こども作品ギャラリー（試作版）

捨てられない子どもの作品・ことば・プレゼントを、写真に撮ってしまっておくWebアプリ（PWA）。
データはすべて端末のブラウザ内（IndexedDB）に保存され、サーバーには送られません。

## 実装した機能（アイデア番号）

| No. | 機能 | 場所 |
|---|---|---|
| 1 | 「ありがとう、さようなら」儀式モード（声の録音＋演出、手放した日を記録） | 作品の詳細 / 保存時 / 連続撮影のまとめ |
| 2 | 現物の保管状況（手元・実家・手放した）＋保管箱＋QRラベル印刷 | 下のタブ「保管」 |
| 5 | 連続撮影（手がどいて静止したら自動撮影）＋まとめて整理 | ホーム「連続撮影」 |
| 6 | 自動補正（四隅検出・ゆがみ補正・紙を白く）＋手動で四隅調整 | 写真を追加したとき |
| 8 | 年齢・学年の自動付与（4/2〜翌4/1区切り、年少〜中学） | すべての作品 |
| 9 | 名言帳・言い間違い辞典（音声入力・声の録音） | 下のタブ「ことば」 |
| 10 | プレゼントの物語カード＋「N年前の今日」表示 | ホーム「プレゼント」・ホームの思い出欄 |
| 20 | まるごと書き出し（フォルダ構成のZIP）・復元・作品集（印刷/PDF） | 右上 ⚙️ |

## パソコンで試す

```bash
python -m http.server 8765
```

ブラウザで http://localhost:8765 を開く（このフォルダで実行）。

## スマホで試す（カメラ・マイクを使うには https が必要）

GitHub Pages などで公開すると、スマホで開いて「ホーム画面に追加」でアプリのように使えます。

## ファイル構成

- `index.html` … 画面の骨組み
- `app.js` … 画面と機能
- `imaging.js` … 画像処理（四隅検出・射影変換・色補正・動き検出）
- `db.js` … データ保存（IndexedDB）
- `style.css` … デザイン
- `sw.js` / `manifest.json` / `icon.svg` … PWA（オフライン対応・ホーム画面追加）
